# NEER

**Cognitive AI Infrastructure**

Local-first, multimodal, multi-channel, and autonomous by design. NEER connects configured agents, model providers, memory, skills, tools, and channel adapters through its Gateway. Actual capabilities depend on provider setup, channel support, and permissions; using a local Gateway does not necessarily keep provider traffic local.
