# `neer tui`

Open the terminal UI connected to the Gateway.

Related:

- TUI guide: [TUI](/web/tui)

## Examples

```bash
neer tui
neer tui --url ws://127.0.0.1:18789 --token <token>
neer tui --session main --deliver
```
