# `neer setup`

Initialize `~/.neer/neer.json` and the agent workspace.

Related:

- Getting started: [Getting started](/start/getting-started)
- Wizard: [Onboarding](/start/onboarding)

## Examples

```bash
neer setup
neer setup --workspace ~/.neer/workspace
```

To run the wizard via setup:

```bash
neer setup --wizard
```
